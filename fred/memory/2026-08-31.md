## Lessons today
- Exec sandbox may isolate localhost: port checks from exec can show DOWN while host services are fine — verify via public URLs (tunnel path) or healthcheck instead.
- After gateway restart, exec sessions die mid-command (missing tool result) — use detached `(sleep 2; launchctl kickstart...) &` pattern.
- Generated HTML onclick: json.dumps() double-quotes break HTML attributes — escape to single quotes.
- macOS cron unreliable post-reboot — prefer LaunchAgents (StartInterval) for scheduled jobs.
